== Audit (C) — 6 tests CI préexistants (corrigés, baby-step TDD)

=== 1. `CodexPluginPublicationTest` ×2 — version injectée par Gradle

Pattern **graphify D5-RACE (S-029) / bakery BKY-CI-ISOLATION (S-243)** : la
garde ne lit plus le *working tree* du repo voisin (`../workspace-bom/...`,
racy inter-sessions et absent en CI isolée). **Gradle injecte** la version
publiée résolue par le catalogue workspace :

[source,kotlin]
----
tasks.test {
    systemProperty("codex.publishedCatalog.codexVersion", ws.versions.codex.plugin.get())
    systemProperty("codex.publishedCatalog.bomVersion", ws.versions.workspace.bom.get())
}
----

`wsCatalogToml()` supprimé ; propriété absente → `error(...)` explicite, jamais
de vert silencieux. Le troisième test (id/groupe stables) est inchangé.

=== 2. `TesseractOcrEngineTest` — `assumeTrue` (binaire absent en CI)

Les tests qui exercent le **vrai** moteur (image propre → vraie confiance TSV,
mapping langue, sourceFormat, image sans texte) sont conditionnés par
`assumeTesseractAvailable()` : sonde `tesseract --version`, `assumeTrue` honnête
(même patron `OllamaProbe`/pgvector). Les tests de **dégradation** (binaire
absent → résultat vide, stub sans TSV) restent déterministes et actifs — c'est
le contrat que la garde protège.

=== 3. Fixtures provenance — jointure d'ancêtre réalignée

Le renommage S-270 (`fa18f33`, Vague 4) avait neutralisé **une seule moitié**
de deux fixtures : le TOC `Organiser le contenu du scénario` → `...du plan`,
mais le chunk était resté `...du scénario` (et inversement pour
`PageProvenanceResolverTest.ancestor`, où le *leaf* du chunk avait divergé).
Le normaliseur étant exact, la jointure ne matchait plus. Correctif minimal :
aligner **les deux côtés** sur la forme générique `Organiser le contenu du
scénario` (le test `joins despite polluted titles on either side` vérifie *par
construction* que des titres réellement divergents ne joignent **pas**).
