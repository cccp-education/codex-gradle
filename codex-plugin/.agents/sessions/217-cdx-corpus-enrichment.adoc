== Travail réalisé

=== Baby-step 1 — SectionTitleNormalizer (19 UT)

*Diagnostic* : la 1re exécution d'enrichissement ne joignait que
30/111 sections titrées (27% de jointure). Cause racine : `matchesSection`
faisait du match case-insensitive exact, mais les titres LDD (AST
AsciidoctorJ) et chunks (SemanticChunker) encodaient différemment :

* entités HTML (`d&#8217;` vs `'`)
* footnotes (`footnote:[102]` vs `<sup>[<a>1</a>]</sup>`)
* apostrophes typographiques vs ASCII
* dot leaders de TOC (`.....` vs rien)
* marqueurs de footnote `[102]`

*Implémentation* : `SectionTitleNormalizer` objet pur —
`normalize(raw)` = unescape HTML → strip footnote macro → strip HTML
tags → strip zero-width spaces → strip footnote markers → strip trailing
dot leaders (2+ chars) → whitespace collapse. Post-lowercase apostrophe
normalization. Ordre corrigé (footnote marker AVANT dot leaders — bug
découvert en RED : `[1]` suivait le dernier `.`).

RED (20 erreurs `Unresolved reference`) → GREEN 19/19.
