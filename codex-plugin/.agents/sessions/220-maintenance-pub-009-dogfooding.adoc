=== Bug P0 découvert — `generateCompositeContext` casse à l'exécution

Run `generateCompositeContext` (US-2 exposition doubt-aware) → **échec** :

----
Execution failed for task ':generateCompositeContext'.
> Serializer for class 'Any' is not found.
----

.Root cause
`CodexCompositeContextTask.execute()` sérialisait `Map<String, Any>` via
`Json.encodeToString(...)`. kotlinx.serialization n'a **aucun serializer
pour `Any`** — l'exécution lève, alors que `check` reste vert. Aucun test
n'exécutait `execute()` : les suites ne couvraient que le wiring des
propriétés (`CodexCompositeContextTaskTest`) et les seams `internal`
(`buildDocsContent`, `searchDoubtAware`). Bug **préexistant** (depuis le
rename S-058 : `mapOf<String, Any>` présent dans le fichier initial,
`git log -S` confirme), jamais détecté car la tâche n'avait jamais été
exécutée en réel. Le contrat N3 (`composite-context.json`) était donc
cassé en production, silencieusement.

.Le pattern voisin faisait déjà bien
`ExportKnowledgeBaseTask` construit son JSON avec `JsonObject`/
`JsonPrimitive` — précisément parce que `Map<String, Any>` ne se sérialise
pas.

=== Correctif — baby-step TDD strict RED → GREEN → REFACTOR

. *RED* — `CodexCompositeContextJsonTest` (3 UT) : `buildCompositeJson`
  et `buildVibecodingJson` absents → 3× `Unresolved reference`.
. *GREEN* — extraction de 2 seams purs dans `CodexCompositeContextTask` :
  `internal fun buildCompositeJson(results, query, topK): String` et
  `internal fun buildVibecodingJson(docsSection, query, topK, count): String`,
  construits via `buildJsonObject`/`JsonPrimitive`/`JsonArray` (pattern
  `ExportKnowledgeBaseTask`). `execute()` consomme les seams.
  `.writeText(buildCompositeJson(results, q, k))` +
  `.writeText(buildVibecodingJson(...))`.
. *REFACTOR* — import du dead code (`mapOf` entries) retiré, `entries =
  results` (la liste `RetrieveResult` typée remplace les maps inline),
  imports kotlinx ajoutés.
. *BDD* — 2 scénarios ajoutés à `codex_doubt_bridge.feature`
  (`The composite context JSON contract is serializable`, `The
  vibecoding JSON contract is serializable`) + 4 step defs préfixés
  "composite JSON"/"vibecoding JSON" (anti-collision S-088). Runner dédié
  existant réutilisé (Économie d'Encre — pas de 10e runner). 7/7 PASSED.
. *Preuve par re-run* — `publishToMavenLocal` + re-run consommateur :
  `generateCompositeContext — 12 entries, docsSection=3206 tokens` OK,
  `composite-context.json` porte 1 entry `doubtful=true` (query
  « comment organiser le contenu d'un scénario pédagogique »), le canal
  Docs expose la provenance + la query pertinente (SPG/SPD).

  `check` vert ne prouve pas que la tâche s'exécute. Les seams `internal`

  le pattern `JsonObject` du voisin (`ExportKnowledgeBaseTask`) était le
