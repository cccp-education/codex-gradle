== Objectif

Unifier `CodexPipelineTask.chunkMd` (constat #7 du cadrage P1 S-077) avec

différée. L'audit S-093 infirme cette hypothèse.

== Audit pré-refactor

`CodexPipelineTask.pipeline()` (lignes 105-137) appelle `chunkMd` à la
ligne 123 mais le résultat n'est utilisé **que pour le log**
(`chunks.size` ligne 128). L'output écrit est `adocContent` (AsciiDoc),
PAS les chunks. Le `mdContent` est aussi éphémère.

Le chemin pgvector réel (indépendant de `chunkMd`) :
----
ExtractBookStructureTask → ConvertToMarkdownTask → ChunkDocumentTask
                                                      ↓
                                            SemanticChunker.chunk()  ← canonical
                                                      ↓
                                              chunks.json → CodexIngestTask → pgvector
----

`chunkMd` ne participe **pas** au chemin pgvector. L'unification est un
**refactor sécuritaire** — le changement observable est limité au log.
