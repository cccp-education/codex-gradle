== CDX-RC-04-2 — PgVectorSessionMemory adapter (functional testcontainers)

`PgVectorSessionMemory` implémente `SessionMemoryContract` (save/load)
via R2DBC + ONNX `AllMiniLmL6V2EmbeddingModel` (lazy). Pattern
`CodexVectorStore`/`CodexIngestTask`.

Bug 1 (compile) : `bind(index, value: Any)` n'accepte pas null →
`bindNull` pour `currentModule`/`lastInteractionAt` nullables + smart
cast via variables locales (propriété d'un autre module).

Bug 2 (R2DBC lazy) : `execute().awaitFirstOrNull()` ne consomme pas le
`Result` → INSERT non exécuté. Corrigé en `.awaitFirst().rowsUpdated.awaitFirst()`
(consomme le Result, déclenche l'INSERT).

Bug 3 (JSONB) : bind String sur colonne JSONB →
`PostgresqlBadGrammarException: column is of type jsonb but expression
is of type character varying`. Corrigé via cast `$3::jsonb` dans le SQL
(R2DBC PostgreSQL ne cast pas automatiquement String → jsonb).

`PgVectorSessionMemoryIT` (5 functional `@Tag("integration")`) :
round-trip complet, upsert overwrite, null pour clé inconnue, clé
composite (même learner ≠ formations = profils distincts), empty profile.
5/5 PASSED (Testcontainers pgvector/pgvector:pg16).
