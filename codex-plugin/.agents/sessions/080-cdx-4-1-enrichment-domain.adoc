== Décisions architecturales

. *Composition sur héritage* — `EnrichedLddNode` compose `LddNode` au
  lieu d'en hériter. `LddNode` est `data class` (non `open`), contrat
  stable consommé par `AsciiDocToJsonLddTask`/`ImportBookSqlTask`. Modifier
  ce contrat casserait la backward compat. La composition préserve le
  contrat et expose les enrichments comme champs supplémentaires.

. *Port `fun interface`* — `GraphifyResolver` est une SAM interface
  (`resolve(sectionTitle): List<String>`). Permet aux tests d'instancier
  avec des `object : GraphifyResolver { override fun resolve(...) = ... }`
  anonymes, et à l'adapter `GraphifyFileResolver` d'implémenter
  naturellement. Pattern mirror `OcrEngine`/`OcrPipeline` (codex.ocr).

. *Zéro dépendance compile graphify* — `GraphifyFileResolver` lit
  `graph.json` via kotlinx.serialization avec son propre modèle privé
  (`GraphFileModel`). Aucun `implementation("...:graphify-gradle:...")`
  dans `build.gradle.kts`. Le contrat N0 est le fichier JSON, pas le
  code. Pattern constat #12 du cadrage S-077 (graphify publie `graph.json`
  mais codex ne le consomme pas — désormais consommé).

. *Dégradé silencieux* — `GraphifyFileResolver` tolère fichier
  manquant/JSON invalide/champ `nodes` absent → retourne empty au lieu
  de crasher. Pattern `OcrResultCache` (économie d'encre : le pipeline
  enrichi fonctionne sans graphify si le fichier n'existe pas).

. *Jointure par dernier segment de sectionPath* — un chunk
  `sectionPath = "Chapter 1 > Architecture"` est joint à la section
  LDD `title = "Architecture"` (dernier segment après `>`). Case-
  insensitive. Rationale : `sectionPath` est hiérarchique, le dernier
  segment est le titre de la section courante — l'ancêtre est du contexte
  (pas le titre direct).

. *Entités par regex capitalized words* — extraction `\b[A-Z][A-Za-z0-9]+
  (?:\s+[A-Z][A-Za-z0-9]+)*\b` sur title + text. Peuple le placeholder
  `DocumentChunk.entities` (constat #3 du cadrage S-077). Simple,
  déterministe, pas d'appel NLP externe. Suffisant pour MVP0 (les entités
  sont des indices, pas une extraction NER complète).

. *Zéro bump BOM* — `kotlinx.serialization.json` déjà en classpath
  (build.gradle.kts:32 `implementation(libs.kotlinx.serialization.json)`).
  `DocumentChunk` et `LddNode` existants consommés (pas modifiés). Pas
  de nouvelle dépendance. Gate MEMPHIS (CDX-RC-04) non touchée.
