== Constats (audit code)

. `FontStyleDetector` (object pur `codex.tasks`) classifie les fontes PDF en
  5 styles via heuristiques nom — 12 mots-clés monospace, 5 bold, 5 italic.
  Aucun test unitaire isolé dédié — couverture uniquement via
  `ExtractBookStructureTaskTest` (6 assertions `assertTrue` noires).
. `ExtractBookStructureTask.computeHeaderThresholds` (lignes 65-77) est un
  calcul pur de thresholds dynamiques h1/h2/h3/h4 à partir de stats font-size
  (avg/max/min/range). Logique typographique pure, candidat extraction.
. `HeaderThresholds` private data class — non testable isolément.

== Décisions

. *FontStyleDetectorTest.kt* — characterization tests de l'objet existant.
  GREEN direct (code existe). 32 unit couvrant : 12 mots-clés monospace ×
  cas nominaux, priorité monospace > bold, 5 variantes bold, 5 variantes
  italic, combinaison BOLD_ITALIC, fallback NORMAL, case-insensitive,
  helpers enum `isMonospace`/`isBold`/`isItalic` pour les 5 valeurs.
. *TypographicAnalyzer* extrait de `ExtractBookStructureTask` — nouvel
  objet pur `codex.tasks.TypographicAnalyzer` + data class publique
  `HeaderThresholds` (sortie du private). `ExtractBookStructureTask.computeHeaderThresholds`
  délègue désormais (`= TypographicAnalyzer.computeThresholds(...)`). -11 lignes.
. *TypographicAnalyzerTest.kt* — 12 unit couvrant : 4 thresholds dynamiques
  (large range), 4 fallbacks (range < 1.0/2.0/3.0/4.0 + zero range), ordre
  h1>h2>h3>h4, plafond max, range négative défensive.
. *Domaine* : `codex.tasks` (inchangé — extraction interne, pas nouveau
  domaine DDD. Le cadrage mentionnait `codex.typography` mais l'extraction
  est restée dans `codex.tasks` car `TypographicAnalyzer` est un collaborateur
  privé de `ExtractBookStructureTask`, pas un agrégat métier. Pas de bump
  BOM, pas de nouveau package.
. *Bug test corrigé* : `"DIN-Regular"` ne matche pas `bd ` (avec espace final).
  Test corrigé pour documenter le comportement réel (`"DIN bd Regular"` → BOLD,
  `"DIN-bd-Regular"` → NORMAL). C'est un bug dans mon assertion, pas dans le code.
