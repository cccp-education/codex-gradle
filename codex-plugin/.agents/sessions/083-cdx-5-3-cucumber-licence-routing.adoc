== Décisions architecturales

. *Pattern S-082 1re application codex* : runner `@Suite` +
  `@SelectClasspathResource` + tâche Gradle `Test` dédiée filtrant
  sur `runnerClass`. Permet d'isoler `codex_export_routed.feature`
  du suite Cucumber global (`src/test/resources/features/*.feature`).
. *Override `cucumber.features`* : le fichier
  `junit-platform.properties` global met
  `cucumber.features=src/test/resources/features` qui ignore les
  `@SelectClasspathResource` (warning Cucumber/JUnit5 known issue).
  Solution : la tâche `cucumberTestLicence` override via
  `systemProperty("cucumber.features", ".../codex_export_routed.feature")`.
. *Glue `codex.bdd`* partagé avec `PipelineSteps` existant — les
  steps de `LicenceRoutingSteps` sont préfixés et uniques
  ("the deploy knowledge base routed task runs...", "the knowledge
  base is exported under...", "the knowledge base contains a...").
. *Pure BDD* : zéro fichier prod modifié. Le domaine `codex.licence`
  (S-081) et la tâche `DeployKnowledgeBaseRoutedTask` (S-082) sont
  exercés via `ProjectBuilder` — aucune nouvelle logique métier.
