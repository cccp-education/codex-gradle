== Détection — signal et calibration

`codex.tasks.TocNoiseDetector` (objet pur, no-I/O) : une **ligne de titre**
(préfixe `#`–`######`) portant une suite de **4 points ou plus** est une entrée
TOC. Le seuil est délibérément étroit :

* `...` (ellipse de titre réel, `1-1.2 Différencier : ...`) → **non flaggé**.
* `3.3.6` (coordonnées pointées) → **non flaggé**.
* prose pointée (`chapitre 1.1.2`) → **non flaggé**.

Mesure sur le **corpus FPA réel** (387 chunks) :

[cols="2,3", options="header"]
|===
| Mesure | Valeur

| Chunks flaggés `isTocNoise` | **33** (entrées TOC pures)
| `sectionPath` portant des dot leaders | 99
| Dont contenu réel (ancêtre TOC pollué uniquement) | 66 — **non flaggés** (contenu retrievable, seul le chemin est bruité)
| Taille des 33 flaggés | 81–132 chars (< 150, plancher pinné)
| Chunks substantiels flaggés | **0** (précision 100 %)
|===

Le choix de ne flagger que le **chunk d'entrée TOC** (et pas ses descendants de
contenu réel, dont le `sectionPath` est pollué par un ancêtre) est ce qui rend
le détecteur sûr : on retire le bruit sans jamais retirer du contenu.
