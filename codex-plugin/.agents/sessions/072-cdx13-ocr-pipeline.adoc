== Architecture

----
[CollectOcrTask] (Gradle, group=collect)
    └─ OcrPipeline(engines=[LlmOcrEngine, TesseractOcrEngine])
        ├─ LlmOcrEngine(client=HttpOllamaChatClient, config=OcrConfig)
        │   └─ HttpOllamaChatClient → POST /api/chat (Ollama vision, base64 images)
        │       → OcrResult.structuredText (AsciiDoc)
        └─ TesseractOcrEngine (fallback local, CLI tesseract)
            → OcrResult.structuredText (texte brut)
    → outputFile: OCR Book.adoc (1 section == Page N par image)
----
