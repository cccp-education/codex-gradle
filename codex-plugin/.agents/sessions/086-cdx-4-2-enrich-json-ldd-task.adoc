== C. Constats clés

. `EnrichedLddNode` était une `data class` pure (S-080) — l'ajout
  d'`@Serializable` est *additif* (pas de reconstruction, pas de bump
  BOM). `LddNode` et `DocumentChunk` sont déjà `@Serializable`.
. `GraphifyFileResolver` (S-080) dégrade silencieusement si le fichier
  `graph.json` est manquant ou invalide → la tâche n'a pas de guard
  supplémentaire, le dégradé est garanti par l'adapter.
. Le test `enrichJsonLdd degrades silently when graph json is missing`
  valide le contrat de dégradé silencieux (pattern `GraphifyFileResolver`
  S-080).
. La tâche ne peuple *pas* `DocumentChunk.entities` directement — le
  `JsonLddEnricher` extrait les entités depuis le `LddNode` (titre +
  texte) et les place sur l'`EnrichedLddNode`, pas sur le chunk. Le
  placeholder `DocumentChunk.entities` reste `emptyList()` — c'est
  l'`EnrichedLddNode` qui porte les entités calculées. Constat
  cohérent avec le design S-080.
