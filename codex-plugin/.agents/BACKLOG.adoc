(page→doute), marche d'ancêtre deepest-first + `ProvenanceTitleNormalizer`.

(cadrage D2) = 24,8 %, marche d'ancêtre + raffinements = **70,8 %**
(274/387). Le grain de jointure est tranché par la mesure. *Déviation D6* :
jointure retrieval → page par `sectionPath` (le `chunkId` de `RetrieveResult`
est le BIGSERIAL pgvector `Long`, pas l'id SHA-256).
