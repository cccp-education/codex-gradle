== Décisions run (US-0)

- RD1 : input = `livre.adoc` (7787 lignes) — source canonique unique
  assemblée. Les 203 pages scans/ restent la source OCR brute (pas
  re-chunkées individuellement — Économie d'Encre).
- RD2 : pipeline Gradle = `transformToMarkdown` → `transformChunk` →
  `deployKnowledgeBase`. Pattern dogfooding mirror FPA-BOOK-4 : build
  script init dans `office/` consommant codex-plugin (mavenLocal 0.0.6
  ou Central), zéro modification du build script codex.
- RD3 : outputs dans `office/metiers/FPA/Devenir_.../codex-out/` (œuvre
  dérivée, jamais dans le repo public codex). Zéro bump BOM, zéro
  publication.
- RD4 : licence chunks = PROPRIETARY (œuvre dérivée du livre FPA —
  LicenseRouter UNKNOWN→office/ ; tag explicite `PROPRIETARY`).
- RD5 : validation US-3 = échantillonnage 10 chunks + invariants globaux
  (ids SHA-256 `chk-…`, sectionPath non vide, content non blank,
  coverage : nombre de chunks ~ nb headings, tailles raisonnables).
- RD6 : les 27 issues OCR (book-ocr-issues.json) = métadonnées de doute
  déjà connues → croisées avec l'échantillonnage US-3 (chunks dérivés
  de pages ILLISIBLE = candidats douteux). OCR-QUALITY-1/2 codex
  traiteront la cause racine en session dédiée.
