== Contexte

FPA (Formateur Professionnel d'Adulte) et CDA (Concepteur Développeur
d'Application) sont des métiers vendus (fond de commerce, talaria.school).
Leur présence dans le nommage d'APIs publiques Apache 2.0 : (1) banalise
le terme du métier dans l'OSS, (2) condamne à des vagues de renommage
coûteuses quand le portefeuille grandit. La bonne heure est maintenant —
les usages sont encore peu profonds (~200 occurrences, 80% tests/docs).

== Décisions de nommage (actées pilote)

|===
| Terme privé | Terme public | Sémantique
| FPA | content | catégorie de contenu pédagogique/documentaire générique
| CDA | coding | catégorie de contenu technique/code
|===

*Principe* : les plugins publics décrivent des capacités (assembler/
valider/ingérer du content, expertiser du coding) — chaque client
apporte son corpus. Le métier (FPA, CDA et futurs) vit en privé
(`office/` + `training-gradle`), jamais dans le nommage public.

== Décisions techniques

- D1 : `FpaPageResolver` → `ContentPageResolver` — la convention split
  pages `NNN_N.adoc` devient une convention content générique (tout
  livre scanné page par page), le FPA n'en est qu'un usage.
- D2 : `fpaAwareResolver()` → `contentAwareResolver()` (signature et
  câblage `AssembleBookTask` suivent).
- D3 : `Domain` codebase → valeurs `CODING` / `CONTENT`. Le couple
  métier FPA/CDA disparaît du code public.
- D4 : défaut `-Pdomain` préservé : `orElse("CODING")` (comportement
  identique à l'ex-CDA défaut).
- D5 : keywords `DeterministicOffTopicDetector` — liste CODING inchangée
  (déjà générique) ; liste CONTENT : `"fpa"` et `"cda"` **sortent** ;
  `qualiopi`, `rncp`, `afnor`, `vae`, `bloom` etc. **restent** (références
  publiques françaises, pas IP du pilote).
- D6 : plantuml registry — `"FPA"` et `"CDA"` sortent du registre
  non-traductible (marques du pilote, pas acronymes génériques).
- D7 : backward compat NON préservée (renommage dur — boroughs jeunes,
  peu de consommateurs externes, moins de dette). Breaking change
  assumé et documenté (README + changelog bump).
- D8 : gouvernance (EPICs, cadrages) renommée avec mention "ex-FPA" en
  historique seulement. AGENTS.adoc racine (privé) garde FPA comme
  terme métier dans les sections privées ; les tables publiques boroughs
  passent aux termes neutres.
